# FitLog 操作プロトタイプ

> 未承認のUI設計。実認証・API・DB・AWSは接続していない。

[index.html](index.html)をブラウザで開く。ビルド・サーバー・外部通信は不要。MyTimelineと同じHTML/CSS/JavaScript方式で、manifestが操作と見た目を固定できるよう単一HTMLにまとめている。

## 操作
8画面（登録、ログイン、全体／フォロー中タイムライン、記録入力・編集、詳細、検索、プロフィール、プロフィール編集）を移動できる。複数種目・セット、画像のプレビュー、記録の作成・編集・削除、コメント、いいね、フォロー、プロフィールを疑似データで操作できる。

上部の利用者切替でSaki/Mika/Renを切り替える。登録メールは架空の`@example.test`を使い、パスワードは全員`demo-only-1234`。本物の認証情報を入力しない。データはlocalStorageの`fitlog.prototype.v2`に保存し、再読込で維持する。リセットで初期データに戻る。保存容量超過の場合はエラー表示し、直前のデータを維持する。

## 本実装との境界
画面上の権限表示や入力検証を確認する用途。サーバーの認証・CSRF・並行処理・ページング・S3障害の保証ではない。写真はブラウザ内データで、本実装のEXIF除去や非公開S3保存は行わない。ネットワークの取得中・失敗・認証期限切れを全て再現するものではない。入力値は画面表示時にエスケープする。

## 確認記録（2026-10-27）
agent-browser 0.39.4で実画面を操作し、PCと375px幅のスクリーンショットを目視した。2種目の記録作成・画像選択・再読込・編集・削除、別利用者の検索・フォロー・いいね、コメント作成・編集・削除、他人の編集削除ボタン非表示、0回の入力拒否、疑似登録・ログアウト後のログイン画面への遷移を確認した。コメント中のHTML文字列が実行されないこと、小画面で横スクロールが出ないことも確認した。終了時にブラウザを閉じた。

プロフィール画像変更、全容量境界、ストレージ枯渇、完全なキーボード操作は未検証。これはモックの操作確認であり、製品E2E合格・独立レビュー結果ではない。
