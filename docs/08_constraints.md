# 10. 制約・前提条件・未決事項

> 壁打ち用の草案。未承認・未実装・独立レビュー未実施。数値・方式は提案であり、実行結果ではない。

## 確定した前提
個人学習用。AWSは低費用、撮影後に破棄する。文書の分類はMyTimeline準拠。通常モードでCodex実装・Claude独立レビュー。GitHub操作はFitLog個人運用の個別承認を維持する。
筋トレ中心で、有酸素の距離・時間は初版に含めない。全記録をログイン利用者全員に公開し、ゲストには公開しない。独自ドメインはなく、購入せずMyTimelineと同じCloudFront提供ドメインと既定証明書を使う。
