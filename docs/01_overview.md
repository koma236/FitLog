## 1. プロジェクト概要
FitLogは、筋トレを記録して振り返り、他の利用者の記録にいいねやコメントを付けるWebアプリ。学習の成果はソース、設計の説明、ローカル検証記録、AWS上の動作動画で示す。
初版は日本語、デスクトップを主対象とする。小画面でも主要操作が崩れないレイアウトにする。
運動範囲はユーザー回答により筋トレ中心で確定。重量・回数・セットを扱い、有酸素の距離・時間は初版に含めない。
恒常的な本番運営、課金、医療・トレーニング指導、可用性保証は目的に含めない。AWSは撮影期間のみ稼働するデモ環境。

## 2. 用語定義
| 用語 | 定義 |
|---|---|
| 記録／投稿 | 1回のトレーニング。実施日、種目、セット、メモ、任意の画像 |
| 種目 | ベンチプレスなど。初版は種目名を直接入力する案 |
| セット | 種目内の1回分のまとまり。重量kgと回数 |
| リレーション | いいね、コメント、フォローという利用者間の関係。DBの外部キー・一意制約でも表現 |
| デモ環境 | デモ用アカウントと再生成できるデータのみを置く、破棄を前提としたAWS環境 |
| モック | 実認証・DB・S3を使わない、画面と操作の相談用成果物 |
